# Watchdogs — AIVM Brain Hub

Deze repo is het koppelpunt tussen je lokale AIVM brain (Obsidian + OpenClaw/Claude agents op je PC) en Perplexity Computer.

## Wat hier staat
- `SYNC-INSTRUCTIONS.md` — instructies voor de lokale agents (wat en hoe te syncen)
- `PRIVACY.md` — regels voor wat wel en niet in deze (publieke!) repo mag
- `brain/` — structuur voor gesyncte kennis (alleen samenvattingen, geen gevoelige data)

## Hoe het gedeelde brein werkt
1. Lokale agents (Claude/OpenClaw) maken samenvattingen van de Obsidian-vault
2. Persoonlijke samenvattingen gaan naar de Notion-pagina "AIVM Brain Sync Inbox" (privé)
3. Algemene, niet-gevoelige kennis mag naar deze repo (zie PRIVACY.md — de repo is publiek)
4. Perplexity Computer leest beide en houdt het AIVM Command Center in Notion actueel
